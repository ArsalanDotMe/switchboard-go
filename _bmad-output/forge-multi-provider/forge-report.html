Multi-provider no switchboard-go

Sessão de forja · trabalho avulso · objetivo: clarificar as possibilidades de incluir outros provedores além do OpenCode Go

Resultado

A ideia resistiu e ficou específica o bastante para usar. O proxy passa a ter tiers de prioridade (OpenCode Go = 0, depois outros provedores e tiers gratuitos), sem tocar na configuração dos agentes Hermes.

Decisões travadas

  • Tiers de prioridade na ordem da config.
  • Cada tier tem um mapa de modelos. Sem mapeamento, o tier é pulado. A substituição é aceita porque só o Eduardo usa.
  • Sem tradução entre OpenAI-style e Anthropic-style. Cada tier declara os estilos que fala.
  • Toda a config fica no proxy. Os agentes mantêm o mesmo URL e a mesma PROXY_API_KEY.
  • Tier pago exige teto diário global, compartilhado entre agentes. Sem ele a config é inválida. O primeiro uso dispara o alerta SMTP.
  • Tiers gratuitos entram como free: true, sem proxy key por agente, porque nenhum agente lida com dado sensível.
  • Falha do upstream (429, 5xx, 401, 402, 404) conta como rate limit: cooldown e próximo tier. O 400 não faz failover.
  • Elegibilidade de modelo: mínimo de contexto e tool calling que o Hermes precisa.
  • A automação de catálogo (modelos novos, limites, quem deixou de ser gratuito) só propõe. A auto-adição fica para depois, começando pelo OpenRouter.

Rejeitado e por quê

  • Cadeia de fallback por request: obrigaria configurar cada agente.
  • Só o mesmo modelo: deixaria OpenAI e Anthropic quase sempre de fora.
  • Tradução entre estilos de API: caro (SSE, tools) e desnecessário para o Hermes.
  • Proxy key por agente: adiada, sem necessidade hoje.

Pontos fracos que sobreviveram

  • Gasto silencioso: um modelo gratuito que vira pago só é detectável por API no OpenRouter. Nos demais, depende de página de documentação. Mitigação: a automação só propõe.
  • Teto compartilhado: um agente em loop pode consumir o teto de todos no dia.
  • Estilo real do Hermes não verificado: confirmar nos logs do proxy. Modelos como MiniMax podem usar /v1/messages.
  • Cooldown dos tiers gratuitos ainda por definir (o 429 deles é por minuto ou por dia).
